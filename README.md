# tim-lgi/homebrew-tap

Homebrew formulae for my tools.

## Install

```sh
brew tap tim-lgi/tap
brew install typerunner
```

## What's here

| Formula | What it is |
|---|---|
| `typerunner` | A terminal typing race game — outrun the pacers, clear the hurdles. [Source](https://github.com/tim-lgi/typerunner) |
